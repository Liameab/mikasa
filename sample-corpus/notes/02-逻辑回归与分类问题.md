# 逻辑回归与分类问题

## 从回归到分类

线性回归的输出是连续值，不适合直接做分类。逻辑回归先把线性输出 z = w·x + b 经过 sigmoid 函数 σ(z) = 1 / (1 + e⁻ᶻ) 压缩到 (0, 1)，解释为样本属于正类的概率。当 σ(z) ≥ 0.5 时判为正类，否则判为负类，因此逻辑回归的决策边界在原始特征空间里仍然是一条（超）直线。

## 交叉熵损失

如果分类任务沿用 MSE，损失函数会变成非凸的，优化困难。逻辑回归改用交叉熵损失：L = −[y·log p + (1−y)·log(1−p)]，其中 p 是模型输出的正类概率。交叉熵从信息论角度看是“用模型分布编码真实分布所需的额外比特数”，最小化它等价于让模型分布逼近真实分布。

对交叉熵求导会发现梯度形式非常干净：∇ = (p − y)·x，梯度大小直接正比于预测与真实之间的残差，预测越错学得越快，这也是它训练稳定的原因之一。

## 多分类与评估

多分类任务常用 softmax 把 logits 变成各类概率分布，配合交叉熵；softmax 是 sigmoid 的多类推广。分类任务的评估指标有准确率、精确率、召回率、F1 等，类别不平衡时准确率会失真，更应关注精确率与召回率的权衡。
