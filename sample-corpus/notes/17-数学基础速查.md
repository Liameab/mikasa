# 数学基础速查：线性代数与概率

## 线性代数要点

矩阵乘法 A(m×n)·B(n×p) → C(m×p)，内层维度必须相等。转置把行列互换：训练里梯度下降更新 w ← w − η∇w 中，w 是列向量时梯度也是列向量，维度要对齐。特征值分解把方阵 A 写成 A = QΛQ⁻¹，Λ 对角线上是特征值，特征值大小反映该方向“拉伸”的程度——PCA 做降维就是取协方差矩阵特征值最大的几个方向做投影。对称矩阵的特征向量彼此正交，协方差矩阵正是对称的。

矩阵求导是看懂反向传播的钥匙：标量对向量求导得到梯度向量；链式法则的矩阵形式把逐层误差传回去。常用结论：∂(aᵀx)/∂x = a；∂(xᵀAx)/∂x = (A + Aᵀ)x；正规方程 w = (XᵀX)⁻¹Xᵀy 正是令这个导数为零解出来的。

## 概率论要点

随机变量描述不确定量。期望是均值：E[X] = Σ x·P(x)，线性性 E[aX + bY] = aE[X] + bE[Y] 对任意（不一定独立的）变量都成立；方差 Var(X) = E[(X − E[X])²] 衡量波动，注意 Var(X + Y) = Var(X) + Var(Y) 只在 X、Y 不相关时成立。

贝叶斯公式 P(A|B) = P(B|A)·P(A) / P(B) 回答“看到结果后原因的概率”：P(A) 是先验，P(B|A) 是似然，P(A|B) 是后验。机器学习里随处可见它的影子——朴素贝叶斯分类、贝叶斯优化的采集函数，乃至“评测样本按真实分布抽样”的统计依据。极大似然估计（MLE）选让观测数据出现概率最大的参数，交叉熵损失与高斯噪声假设下的 MLE 是一回事。

独立同分布（i.i.d.）假设是统计学习的基础：训练样本被视为从同一未知分布中独立采样，模型的测试误差才有理论可谈。而偏差-方差分解告诉我们，模型总误差 = 偏差²（模型够不够强）+ 方差（对数据扰动敏不敏感）+ 噪声（不可约），正则化正是在偏差与方差之间做权衡。
