# 模型评估与实验方法

## 数据集划分与评估指标

严谨的实验必须把数据分成训练集、验证集和测试集：训练集学参数，验证集调超参数与做早停，测试集只在全部决定做完后评估一次，防止“对着测试集调参”造成的乐观偏差。数据少时用 K 折交叉验证（轮流拿一份做验证）更稳妥。

分类指标要区分场景：准确率 = 正确数 / 总数，类别不平衡时会失真；精确率（Precision）= TP / (TP + FP)，回答“预测为正的里面有多少真对”；召回率（Recall）= TP / (TP + FN)，回答“真正的正例找回了多少”。二者此消彼长，常用 F1 = 2·P·R / (P + R) 取调和平均做综合；排序/检索任务则用 Recall@K、MRR、nDCG 等衡量“真相关项排得多靠前”。

## 对照实验与结论的严谨性

验证“某个改进是否有效”要做消融实验（Ablation）：在固定其他一切条件的前提下，只切换目标组件（如关掉混合检索的某一路、换掉分词器），观察指标变化。控制变量是消融的灵魂——如果同时改了两处，指标变化就无法归因。

做实验还要注意：多次运行取均值并报告方差，避免单次随机种子带来的假象；不同模型/方法对比要固定可复现的配置快照（超参数、语料版本、随机种子）；“没提升”和“负提升”同样是合法且有价值的结论，如实记录失败案例比只报喜更能帮助判断一个方向该不该继续投入。好实验的标准是：别人拿到你的配置和代码，能复现出你报告里的数字。
